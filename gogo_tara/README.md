# Tara AI Assistant

A personal AI assistant inspired by Jarvis, built with a Python backend using OpenAI GPT and a Flutter frontend supporting voice and text interaction.

---

## Features

- Conversational AI powered by GPT-4
- Voice input using Flutter's `speech_to_text` plugin
- Text-to-speech responses with Python's `pyttsx3`
- System command execution (e.g., open apps, run commands)
- Cross-platform Flutter app for desktop and mobile
